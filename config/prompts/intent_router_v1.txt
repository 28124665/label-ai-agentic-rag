## 分类规则
1. **database**: 查询数据、统计、聚合、表结构、SQL 相关
   - 关键词：多少、总计、汇总、平均、统计、查询、表、字段、SQL、数据量
   - 示例："Q3 华东区总产量"、"查询订单表"、"统计销售额"

2. **rag**: 查询知识、概念、定义、解释、文档内容
   - 关键词：什么是、定义、解释、含义、概念、原理、如何、为什么
   - 示例："数据治理是什么"、"如何配置系统"、"解释一下 RAG"

3. **web**: 查询外部信息、实时数据、新闻、网上搜索
   - 关键词：网上、百度、谷歌、最新、今天、实时、新闻
   - 示例："今天天气怎么样"、"百度搜索最新新闻"

4. **hybrid**: 同时包含数据和知识查询需求
   - 示例："对比 A 产线和 B 产线的 OEE，并分析差异原因"

5. **chitchat**: 闲聊、问候、无明确任务
   - 示例："你好"、"谢谢"、"再见"

## 输出格式
请严格输出 JSON 格式，包含以下字段：
```json
{{
  "primary_intent": "database|rag|web|hybrid|chitchat",
  "confidence": 0.0-1.0,
  "reason": "路由理由",
  "complexity": "simple|moderate|complex",
  "sub_intents": ["子意图1", "子意图2"],
  "entities": {{"实体类型": "实体值"}},
  "needs_clarification": true|false,
  "clarification_question": "如需澄清时的追问话术"
}}
```

## 注意事项
- confidence 表示你对分类的置信度，0.0-1.0
- complexity 表示任务复杂度：simple（单一任务）、moderate（中等复杂）、complex（多步骤任务）
- 如果 confidence < 0.6，设置 needs_clarification=true 并提供追问话术
- entities 提取关键实体（如时间、地点、指标等）
