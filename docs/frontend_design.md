# Agentic RAG 系统前端页面设计文档

> **项目名称**：Agentic RAG 智能知识问答系统  
> **文档版本**：V1.0  
> **目标用户**：企业高管、中层管理人员、知识工作者  
> **技术栈**：React 18 + TypeScript + Next.js 14 + Tailwind CSS + shadcn/ui

---

## 一、设计原则

### 1.1 核心设计原则

| 原则 | 描述 | 示例 |
|------|------|------|
| **简洁优先** | 界面简洁，功能聚焦，避免信息过载 | 对话界面只保留核心交互元素 |
| **渐进披露** | 复杂功能分层展示，按需展开 | 高级配置默认折叠，点击展开 |
| **实时反馈** | 操作即时反馈，状态清晰可见 | 流式响应、加载状态、成功/失败提示 |
| **一致性** | 统一的交互模式和视觉语言 | 所有列表页使用相同的筛选、排序、分页组件 |
| **可访问性** | 支持键盘导航、屏幕阅读器 | 所有交互元素都有明确的 ARIA 标签 |

### 1.2 响应式设计

| 断点 | 宽度 | 布局策略 |
|------|------|----------|
| Mobile | < 768px | 单列布局，侧边栏折叠 |
| Tablet | 768px - 1024px | 双列布局，侧边栏可折叠 |
| Desktop | > 1024px | 多列布局，侧边栏固定 |

#### 3.1.2 功能组件清单

| 组件 | 功能 | 交互细节 |
|------|------|----------|
| **ConversationList** | 对话列表管理 | 新建、删除、重命名、搜索、置顶 |
| **MessageItem** | 消息展示 | 用户消息、AI 回复、工具调用卡片 |
| **ToolCallCard** | 工具调用展示 | 显示调用的工具、参数、结果、耗时 |
| **DataTable** | 数据表格展示 | 支持排序、筛选、导出 |
| **ReferenceCard** | 引用来源卡片 | 显示文档来源、数据库来源、Web 来源 |
| **MessageInput** | 消息输入框 | 支持文本、文件、语音输入 |
| **StreamingIndicator** | 流式响应指示 | 打字机效果、加载动画 |
| **DebugPanel** | 调试面板（可折叠） | 显示状态图执行流程、节点输入输出 |

#### 3.1.3 交互流程

```
用户输入 → 发送消息 → 显示"思考中"状态
    ↓
意图路由 → 显示"正在分析意图..."
    ↓
工具调用 → 显示工具调用卡片（SQL/检索/Web）
    ↓
结果返回 → 流式显示 AI 回复
    ↓
引用标注 → 显示引用来源卡片
    ↓
完成 → 显示完整回复 + 调试信息（可展开）
```

### 5.3 API 接口设计

#### 对话相关

```typescript
// 创建对话
POST /api/v1/conversations
{
  "agent_id": "string",
  "title": "string"
}

// 发送消息（流式）
POST /api/v1/conversations/:id/messages
{
  "content": "string",
  "files": ["file_id"]
}
// Response: SSE stream

// 获取对话历史
GET /api/v1/conversations/:id/messages?page=1&size=20

// 获取对话调试信息
GET /api/v1/conversations/:id/debug
```

#### 知识库相关

```typescript
// 创建知识库
POST /api/v1/knowledge-bases
{
  "name": "string",
  "description": "string",
  "embedding_model": "string"
}

// 上传文档
POST /api/v1/knowledge-bases/:id/documents
// multipart/form-data

// 检索测试
POST /api/v1/knowledge-bases/:id/search
{
  "query": "string",
  "top_k": 5,
  "threshold": 0.7
}
```

#### 数据源相关

```typescript
// 创建数据库连接
POST /api/v1/datasources
{
  "name": "string",
  "type": "postgresql",
  "host": "string",
  "port": 5432,
  "database": "string",
  "username": "string",
  "password": "string"
}

// 测试连接
POST /api/v1/datasources/:id/test

// 获取表结构
GET /api/v1/datasources/:id/tables

// 执行 SQL
POST /api/v1/datasources/:id/query
{
  "sql": "string"
}
```
