# 混合召回引入 Skill 选择 — 设计与改造方案（v1.0）

## 背景

当前 `SkillResolver.resolve()` 的选择路径中，只有**纯关键词子串匹配**（`_ranked_keyword_candidates`），使用 `str.__contains__` 判断用户问题是否命中 `intent_keywords`，按命中长度降序排列后遍历选取第一个合法候选。

独立模块 `SkillRouter`（`router.py`）已实现完整的 6 Stage 混合召回流水线（BM25 + Embedding + RRF + LLM Reranker），但处于**未接入生产**状态，仅被 `shadow_router.py` 引用。

本方案将 `SkillRouter` 的混合召回能力接入 `SkillResolver` 的生产选择路径，替代当前的纯关键词匹配。

---

## 一、现状分析

### 1.1 当前 Skill 选择路径

```
SkillResolver.resolve(context)
  ├─ skill_id 显式 → get_by_id → _resolve_report_skill()  [精确命中，保留]
  ├─ report_type 显式 → get_report_by_type → _resolve_report_skill()  [精确命中，保留]
  ├─ keyword 路径 → _ranked_keyword_candidates()  [纯关键词，替换]
  │     └─ _resolve_report_skill() 遍历候选（前置过滤 + 依赖解析）
  ├─ tenant_default → 精确命中  [保留]
  └─ fallback → generic_analysis  [保留]
```

### 1.2 目标模块及其状态

| 模块 | 文件 | 状态 | 生产接入 |
|------|------|------|:--------:|
| `SkillRouter` | `router.py` | 6 Stage 完整，但 `_build_resolve_result` 返回 `skill_set=None` | ❌ |
| `BM25Retriever` | `retrievers/bm25.py` | 完整，支持 `rank_bm25` 和 Counter 降级 | ❌ |
| `EmbeddingRetriever` | `retrievers/embedding.py` | 完整，`embed_func` 回调注入 | ❌ |
| `SkillReranker` | `reranker.py` | 完整，LLM 重排 | ❌ |
| `HardFilter` | `filters.py` | 完整，等价于 `resolver._prefilter_skill` | ❌ |
| `DecisionPolicy` | `decision_policy.py` | 完整，5 种决策 | ❌ |
| `SkillCard` 构建 | `card.py` | 完整，`CatalogBuilder` 推导 | 部分（构建在 `loader.py` 中） |
| BM25 索引构建 | `loader.py:204` | 存在，但 `cards_by_key` 可能为 None 时跳过 | 部分 |
| `SkillResolver` | `resolver.py` | 生产主力，关键词匹配 | ✅ |

### 1.3 核心差距

`SkillRouter` 的 `_build_resolve_result()` 返回 `skill_set=None`（`router.py:452`），无法直接替代 `SkillResolver`: 它只做路由决策，不完成 `ResolvedSkillSet` 的依赖解析和构建。

而 `SkillResolver._resolve_report_skill()` 完整地做了：
1. 前置过滤（lifecycle → tenant → permission → runtime capability）
2. 依赖解析（DataSkill / RetrievalSkill）
3. 依赖级过滤
4. `ResolvedSkillSet` 构建

## 二、改造方案

### 总体设计

**不替换 `SkillResolver`，只在keyword路径中注入混合召回**。保持 `SkillResolver.resolve()` 的 5 级优先级结构不变，只替换 `_ranked_keyword_candidates()` 的实现内核。

```
SkillResolver.resolve(context)
  ├─ skill_id 显式 → 精确命中  [不变]
  ├─ report_type 显式 → 精确命中  [不变]
  ├─ keyword 路径 → [混合召回新路径]  [替换]
  │     ├─ Stage 1: 硬过滤（HardFilter，复用 _prefilter_skill 逻辑）
  │     ├─ Stage 3: 领域分类
  │     ├─ Stage 4: 混合召回（BM25 + Embedding + RRF）
  │     ├─ Stage 5: 候选排序（召回分数，可选 LLM Reranker）
  │     └─ 遍历候选 → _resolve_report_skill() 构建完整 ResolvedSkillSet
  ├─ tenant_default → 精确命中  [不变]
  └─ fallback → generic_analysis  [不变]
```

### 关键设计决策

| 决策 | 选项 | 选择 |
|------|------|:----:|
| 替换方式 | 替换 Resolver / 注入 Resolver | **注入 Resolver**（保持优先级结构） |
| 召回路径 | 混合召回覆盖 keyword 路径 / 全部替换 | **仅替换 keyword 路径** |
| 前置过滤 | 沿用 HardFilter / 复用 `_prefilter_skill` | **复用 `_prefilter_skill`**（避免重复实现） |
| 候选排序 | 召回分数直接排序 / LLM Reranker | **配置化**（默认召回分数排序，可选 Reranker） |
| 降级策略 | BM25 不可用时走原关键词 | **BM25 降级 → 原关键词** |

### 步骤 3：新增 `_hybrid_recall_candidates()` 方法

替换 `_ranked_keyword_candidates()` 为混合召回实现。

**文件**：`agent/langgraph/skills/resolver.py`

```python
def _hybrid_recall_candidates(self, user_question: str, context: SkillResolveContext) -> list[ReportSkill]:
    """混合召回候选（BM25 + Embedding + RRF），降级到原关键词匹配。
    
    流程：
        1. 前置过滤：用 _prefilter_skill 过滤所有 ReportSkill，得到合法候选
        2. 领域分类：规则分类器，缩小候选范围
        3. 混合召回：BM25（+ Embedding 可选）+ RRF 融合
        4. 排序：按召回分数降序
        5. 降级：BM25 不可用时，走原 _ranked_keyword_candidates()
    """
    # 1. 前置过滤：获取所有合法候选
    all_reports = [
        skill for skill in self.registry.list_all()
        if isinstance(skill, ReportSkill) and self._prefilter_skill(skill, context) is None
    ]
    if not all_reports:
        return []
    
    # 2. 尝试混合召回
    if self._bm25 is not None:
        try:
            # 构建 SkillCard 映射（从 registry snapshot 获取）
            cards = self._build_cards_for_recall(all_reports)
            # 领域分类
            domains = classify_domains_by_rule(user_question)
            domain_filtered = self._filter_cards_by_domain(cards, domains)
            # 混合召回
            recall_results = self._hybrid_recall(user_question, domain_filtered)
            if recall_results:
                # 召回结果 → ReportSkill 列表
                return self._recall_to_report_skills(recall_results, all_reports)
        except Exception as e:
            logger.warning("[SkillResolver] 混合召回异常，降级为关键词匹配: %s", e)
    
    # 3. 降级：原关键词匹配
    return self._ranked_keyword_candidates(user_question)
```

### 步骤 5：更新 `SkillResolver` 工厂函数

**文件**：`agent/langgraph/nodes/intent_router.py`

```python
def get_skill_resolver() -> SkillResolver:
    global _skill_resolver_instance
    if _skill_resolver_instance is None:
        registry = SkillRegistry()
        # 从 registry snapshot 获取构建好的 BM25 索引
        snapshot = registry._catalog  # 或通过公开方法获取
        bm25_retriever = None
        if snapshot.bm25_index is not None:
            bm25_retriever = BM25Retriever()
            bm25_retriever._index = snapshot.bm25_index

            bm25_retriever=bm25_retriever,
            # embedding_retriever 暂不注入（P2+）
            # reranker 暂不注入（P2+）
        )
    return _skill_resolver_instance
```

## 六、降级与边界条件

### 6.1 降级矩阵

| 条件 | 表现 | 降级路径 |
|------|------|:--------:|
| `enable_embedding=False` | 仅 BM25 召回 | 单路 BM25 结果 |
| BM25 索引未构建 | 空索引 | `_ranked_keyword_candidates()` |
| BM25 召回零结果 | 空列表 | `_ranked_keyword_candidates()` |
| 所有候选前置过滤失败 | 空列表 | tenant_default / fallback |
| `agent_config.skill_router.enabled=False` | 请求级关闭 | `_ranked_keyword_candidates()` |
| `embedding_retriever=None` | Embedding 不可用 | 仅 BM25 |

### 6.2 边界条件

| 条件 | 处理 |
|------|------|
| 用户问题为空 | Stage 0 返回空，走 fallback |
| `bm25_index` 为空索引 | `search()` 返回空列表，触发 keyword 降级 |
| 前置过滤后无合法候选 | 跳过混合召回，直接走 tenant_default/fallback |
| 召回结果中存在重复 skill_id | 去重（按最高分保留） |
| 召回结果中的 Skill 不在 `registry` 中 | 跳过（`_recall_to_report_skills` 过滤） |

### 9.2 `_hybrid_recall_candidates` 核心逻辑

```python
def _hybrid_recall_candidates(self, user_question: str, context: SkillResolveContext) -> list[ReportSkill]:
    # 请求级关闭
    agent_config = context.agent_config or {}
    router_config = agent_config.get("skill_router", {})
    if not router_config.get("enabled", self._recall_config.enabled):
        return self._ranked_keyword_candidates(user_question)
    
    # 1. 前置过滤 → 合法候选
    all_reports = [
        s for s in self.registry.list_all()
        if isinstance(s, ReportSkill) and self._prefilter_skill(s, context) is None
    ]
    if not all_reports:
        return []
    
    # 2. BM25 召回
    if self._bm25 is not None:
        try:
            cards = self._to_cards(all_reports)  # ReportSkill → SkillCard
            if not cards:
                return self._ranked_keyword_candidates(user_question)
            domains = classify_domains_by_rule(user_question)
            domain_filtered = self._filter_by_domain(cards, domains)
            if not domain_filtered:
                return self._ranked_keyword_candidates(user_question)
            results = self._bm25.search(user_question, self._recall_config.bm25_top_k)
            if results:
                return self._scored_to_skills(results, all_reports)
        except Exception:
            pass
    
    return self._ranked_keyword_candidates(user_question)
```
